# Al-Masar (المسar) - Fiqh Perancangan & Strategi Dakwah PWA

Aplikasi Web Progresif (PWA) interaktif berdasarkan karya agung Syeikh Muhammad Ahmad Ar-Rasyid: **Al-Masar (Fiqh Perancangan Dakwah)**.

## Ciri-Ciri Utama:
- 📱 **Sokongan PWA (Progressive Web App):** Boleh dipasang terus di telefon pintar (Android/iOS) dan desktop seperti aplikasi asli.
- ⚡ **Mod Luar Talian (Offline Mode):** Dilengkapi dengan Service Worker untuk akses tanpa sambungan internet.
- 🔍 **Carian Interaktif:** Carian pantas topik, dalil, dan strategi dakwah.
- 🎨 **Antaramuka Moden:** Reka bentuk elegan dan mesra pengguna (tema gelap dakwah).
